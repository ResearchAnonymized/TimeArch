# ANSE — Artifact-Driven Autonomous Software Engineering

ANSE is an AI-native software engineering toolchain for autonomous development across the complete lifecycle. Tools collaborate through **explicit engineering artifacts**, coordinated by **KERKIS**.

**[Open the interactive ANSE architecture →](./anse.html)**

That page is the primary visualization (HTML/CSS — editable, not a static diagram image). It covers:

1. Connected lifecycle — RE → Architecture → Coding → QA → Deployment → Runtime  
2. Existing vs planned vs runtime status  
3. Artifact flow under each stage  
4. Requirements → early test cases  
5. QA as lifecycle-wide verification  
6. Deployment to a running, verified system  
7. KERKIS as the orchestration backbone (not a stage)  
8. Shared engineering memory  
9. Continuous production feedback / change management  
10. Ecosystem tool cards (placeholders where names/URLs are TBD)
